# Primeros Auxilios

Web móvil para guiar los primeros auxilios en una emergencia: situaciones ordenadas por frecuencia, pasos cortos con animaciones 3D, voz, metrónomo de RCP y cronómetro de convulsiones.

- 6 idiomas (según el idioma del dispositivo): es, en, fr, pt, de, it
- Número de emergencia según el país (zona horaria / región), editable
- Sin dependencias: abre `index.html`

> Guía orientativa. No sustituye a una formación en primeros auxilios ni a los servicios de emergencia.

Cómo se generan los vídeos, la voz y el vídeo promocional: [3d/README.md](3d/README.md)
